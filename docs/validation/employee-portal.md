# 轻量员工网页入口

## 使用

打开知识库服务根地址，例如本机 `http://127.0.0.1:8765/`。点击“连接知识库”，输入已有成员访问码。页面仅在内存中持有令牌，刷新或关闭后重新输入；不会把令牌存入 URL、浏览器持久存储或页面源文件。

1. 上传区域必须显式选择所属事业部，只有一个可选事业部也不会自动代选。
2. 点击或拖入一份文件，确认资料名称、类型和可选型号后提交。大小上限来自服务端配置。
3. 提交生成草稿，后台解析和向量化，页面展示处理状态；发布继续沿用负责人审核流程，本页面不提供发布或权限管理。
4. 右侧按名称、型号或关键词搜索已发布文件，并按事业部和资料类型筛选；下载原件时仍校验当前身份权限。
5. “待审核提交”显示当前身份有权查看的草稿；普通成员看到本人的提交，负责人也可看到职责范围内的提交。

上传中断可重试，同一次尝试复用上传幂等键和提交信息。失败时可放弃重试重新填写；这不会删除服务器已有资料，重新填写前应检查待审核列表，避免人工重复提交。

## 实现

原生 HTML/CSS/JavaScript，由现有 FastAPI 服务提供，无新增前端服务、构建链或第三方 CDN。新增 `/v1/portal-session` 仅返回认证身份及上传大小上限，其余操作复用原接口。页面只显示当前账号有权提交的事业部，不默认选择“公司公共知识”。
