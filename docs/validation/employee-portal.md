# 员工网页与账号授权

## 登录与加入

打开知识库根地址（本机 `http://127.0.0.1:8765/`），使用邮箱和密码登录。首个开发人员首次登录必须修改初始密码。其他人只能通过管理员登记并生成的邀请链接加入，页面自动填入只读邮箱，要求初始密码填写两次。链接默认七天有效、单次使用；重发使上一链接失效。忘记密码时由有权管理员生成密码重置链接。

网页登录会话保存在 HttpOnly cookie 中，不将密码或会话凭证写入 localStorage；HTTPS 下 cookie 设置 Secure。退出清除当前会话；改密、账号停用或角色调整撤销该账号已有会话及 AI 授权。旧访问码管理与共享码认证停用。

## 三级权限

开发人员可邀请和管理开发人员、管理员、普通用户，管理全部事业部。管理员可邀请并管理自己登记、仍在其事业部管理范围内的管理员和普通用户，不能邀请开发人员，并审核本部门文件。普通用户可提交和检索有权访问的资料，无邀请权限。服务器逐请求检查权限，不能依靠前端选择越权，不能停用或降级最后一个有效开发人员。

在“账号管理”输入对方邮箱、选择角色和事业部，生成链接后复制并自行分享；项目不会自动发邮件。默认分享地址来自受保护运行配置 `AGICO_KB_PUBLIC_URL`，也可明确填写同事可访问的知识库地址；本机地址不能用于其他电脑。

## 上传、审核、预览

可以选择文件、整个文件夹，或拖入文件夹及所有层级子文件夹。默认包含其中所有文件，显式选择本批所属事业部，不根据内容猜测。上传进入待审核流程；完成解析的文件排在前面，负责人审核后发布。普通用户查看自己的提交，管理员查看本部门，开发人员可管理全部部门。

图片、PDF、Office 点击缩略图或文件名进入只读全文预览，支持滚动、页码跳转、旋转和缩放，默认 75%。CAD 等通过图像预览定位原文件。所有原件、缩略图、预览页重新检查当前权限，不因曾加载缓存绕过撤回或停用。

## 连接 AI 助手

登录后点击“连接 AI 助手”，选择 Codex、Accio 或通用 AI 助手。配置片段只包含 MCP 地址，不含员工密码、共享访问码或静态 Authorization。支持 OAuth 的客户端打开知识库网页登录，由本人确认授权，再验证 initialize、工具列表及 kb_catalog；不支持 OAuth 的客户端不能绕过认证。上传前仍需明确所属事业部。

网页提供的是配置指令，不能声称客户端已连接。服务可达、OAuth 完成、当前 Agent 实际工具调用分别验证。已有客户端需要移除同名服务的旧静态 Authorization 请求头并重新授权；Codex 可执行 `codex mcp login agico-kb`。

本次账号功能的验证记录见[账号验收](account-login-20261013.md)。历史访问码测试报告是旧模式的证据，不能用作账号模式的连接说明。
