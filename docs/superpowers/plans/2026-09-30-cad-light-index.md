# CAD 轻量索引实施计划

**目标：** DWG/DXF 原件可立即审核发布；发布后项目后台提取原生文字、块属性及出处供 RAG 检索，不推断几何或工程尺寸关系。验证后清理当前已发布 CAD，供用户重新上传测试。

**已确认设计：** 原件入库与解析解耦。DWG 经本机 ODA 转换器在临时目录转为 DXF，DXF 由 `ezdxf` 只读提取 TEXT、MTEXT 和块属性。提取失败时维持文件库可用并给出原因；原件和人工审核状态不受影响。每个可检索片段带布局、图层、对象句柄等出处。仅索引原生文字，图形及精确尺寸关系不作 AI 转述。

## 实施与验证

- [ ] 在 `tests/unit/test_cad_parsing.py` 写新建 DXF/DWG 的失败测试，覆盖文字、属性、出处、空图与转换失败。
- [ ] 在 `src/agico_kb/cad.py` 实现只读提取；`ingestion.py` 路由 DWG/DXF；将 `ezdxf` 作为项目依赖。
- [ ] 在 CAD 合同测试中先验证原件立即可发布，再验证发布后自动排队、项目 worker 自行生成索引和检索结果。
- [ ] 修改 `lifecycle.py`，在 CAD 发布事务内排入后台任务，不改变其他文件审核流程。
- [ ] 配置受控的 ODA 转换器路径，补充安装脚本、运行说明与明确降级提示。
- [ ] 运行针对性与相关回归测试；用全新临时图纸做真实转换、提取、检索闭环；重启服务核验。
- [ ] 确认所有已发布 CAD 文档只包含 CAD 版本，记录清理前范围；用项目删除流程仅清理这些文档，复核其他类型文件数量和已发布 CAD 数量。

**限制：** 不修改 `D:\测试文件\CAD`、已上传原件或任何生产解析内容；不手工填充 CAD 索引。清理前必须证明新上传的图纸能由项目自身完成后台解析。
