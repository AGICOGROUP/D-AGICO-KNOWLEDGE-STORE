# 改名 Skill 与知识库共享规则

唯一规则源是 `src/agico_kb/ai_naming_rules.md`，正文、语言代码、快速检查类型清单和结构约定一起发布。不要在 Skill 中另写或另存一份长期独立维护的规范。

已授权客户端通过 `GET /v1/naming/rules` 获取 `version`、`sha256`、`rules`、`contract`。Skill 更新时同步正文并核对 SHA-256；无法联网的客户端随 Skill 携带该文件，并随规则版本更新。规则文件不含账号、访问凭证或 API 密钥。

员工流程：Skill 读取资料并依据同一规则改名，保留原件备份且不编造缺失字段；员工选定事业部后上传。知识库对已提交名称执行本地检查，合格时保留名称，跳过命名模型和命名阶段原件读取；未通过时继续已有 AI 命名和必要的人工核对。解析正文、建立索引和审核发布照常执行。

例如 `AGICO_产品宣传册_EN.pdf` 可通过快速检查；`scan001.pdf`、`未知_设备清单.pdf`、无效日期或字段错序不能通过。图纸可保留已有图号，例如 `回转窑_RK-081_总装图_ZH_R1.dwg`。未列入快速检查类型清单的名称仍交 AI 判断，不代表禁止上传。

快速检查仅验证命名结构和必要字段，不验证文件内容，也不凭文件名创建、合并或变更项目归属。审核记录以 `method=filename_rules` 区分本地检查与 AI 生成，保留规则版本及摘要。正式项目关联、事业部权限、原文件及原文件名不因快速检查被改写。
